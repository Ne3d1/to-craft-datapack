# TO CRAFT DATAPACK
A datapack to add crafts for enchanted books and more utilties - Current version: 2.0.0

## Content
Put in the game the old neterite crafts and other balanced crafts for difficult items.
Also with this datapack you have a copletly new enchantment. Wither enchantment that puts your victim in effect of wither wile you kill it. 

Recomiendation: use JEI to watch all recipies
